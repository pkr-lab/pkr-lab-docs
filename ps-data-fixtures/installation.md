# Installation

Es gibt nichts zu installieren. Das Repo ist eine reine Datensammlung.

```sh
git clone https://github.com/pkr-lab/ps-data-fixtures.git
```

Das Repo enthält etwa 750 Dateien und ist klein (unter 1 MB in `.git`). `.DS_Store`-Dateien aus macOS sind versioniert und können ignoriert werden.
