## Navigation

Schüler/innen finden ihre Dateien unter:
```
Ausbildungsjahr_[1-3]/[FACHBEREICH]/Vorname_Nachname_HEXCODE/
```

## Dateibenennungskonvention

Für Schülerarbeiten:
```
[Kürzel]_[Präfix]_[Suffix]_[Nummer].[Format]
```

- **Kürzel**: Schülerkürzel (1. Buchstabe Vorname + 1. Buchstabe Nachname + 3. Buchstabe Nachname)
- **Präfix**: Themenbereich
- **Suffix**: Spezifisches Konzept oder Thema
- **Nummer**: 3-stellig (001, 002, ...)
- **Format**: .pdf oder .docx

### Beispiele
- `PKE_Java_ArrayList_001.pdf` (Peter Kretzer)
- `XBu_Python_Dict_002.docx` (Xenia Bauer)
- `LKc_Datenbanken_Query_003.pdf` (Liam Koch)
- `NBu_Netzwerktechnik_TCP_004.docx` (Noah Bauer)
- `AMl_Zahlensysteme_Binär_005.pdf` (Anna Müller)
- `OZm_PowerShell_Cmdlets_006.pdf` (Olivia Zimmermann)
