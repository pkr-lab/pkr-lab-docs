# IT-Ausbildung SharePoint - Gesamtverzeichnis

## Hauptbereiche

### Ausbildungsjahrgänge
- `Ausbildungsjahr 1` - Anfänger
- `Ausbildungsjahr 2` - Fortgeschrittene
- `Ausbildungsjahr 3` - Abschlussjahr

Pro Jahrgang: ~40 Schüler/innen verteilt auf 5 Fachbereiche

### Lehrpläne & Richtlinien
- `Lehrplan` - Alle Lehrpläne nach Fachbereich
- `Richtlinien` - Allgemeine Richtlinien und Guidelines
- `Sicherheit` - Sicherheitsrichtlinien

### Vorlagen
- `Vorlagen` - Projekt- und Berichtsvorlagen für alle Fachbereiche

### Ressourcen
- `Ressourcen` - Code Style Guides, Glossar, etc.
- `Gemeinschaftliche Ressourcen` - Codebeispiele, Dokumentation, Links

### Verwaltung & Tooling
- `Verwaltung` - Jahrgangsplan, Stundenpläne, Schulferien
- `Tooling` - Scripts, Templates, Checklisten

### Archiv
- `Archiv` - Ältere Jahrgänge und abgeschlossene Projekte

## Benutzergruppen

- **Schüler/innen**: Zugriff auf eigene Ordner und Gemeinschaftliche Ressourcen
- **Lehrer/innen**: Zugriff auf alle Bereiche
- **Administratoren**: Vollzugriff

## Navigation

Schüler/innen finden ihre Dateien unter:
```
Ausbildungsjahr_[1-3]/[FACHBEREICH]/Vorname_Nachname_HEXCODE/
```

## Dateibenennungskonvention

Für Schülerarbeiten:
```
[Kürzel]_[Präfix]_[Suffix]_[Nummer].[Format]
```

- **Kürzel**: Schülerkürzel (1. Buchstabe Vorname + 1. Buchstabe Nachname + 3. Buchstabe Nachname)
- **Präfix**: Themenbereich
- **Suffix**: Spezifisches Konzept oder Thema
- **Nummer**: 3-stellig (001, 002, ...)
- **Format**: .pdf oder .docx

### Beispiele
- `PKE_Java_ArrayList_001.pdf` (Peter Kretzer)
- `XBu_Python_Dict_002.docx` (Xenia Bauer)
- `LKc_Datenbanken_Query_003.pdf` (Liam Koch)
- `NBu_Netzwerktechnik_TCP_004.docx` (Noah Bauer)
- `AMl_Zahlensysteme_Binär_005.pdf` (Anna Müller)
- `OZm_PowerShell_Cmdlets_006.pdf` (Olivia Zimmermann)

### Alle Präfixe & Suffixe

| Präfix | Suffixe |
|--------|----------|
| **Java** | ArrayList, HashMap, Collections, Streams, Lambda, Threads, JPA, Generics, Exceptions, Reflection |
| **Python** | List, Dict, Tuple, Classes, Decorators, Modules, Generators, Context_Manager, Comprehensions, AsyncIO |
| **Datenbanken** | Query, Index, Trigger, View, Normalisierung, Constraints, Joins, Transactions, Backup, Replikation |
| **Netzwerktechnik** | TCP, UDP, DNS, DHCP, Firewall, VPN, Routing, SMTP, HTTP, SSL_TLS |
| **Zahlensysteme** | Binär, Hexadezimal, Oktal, Konvertierung, Bitoperationen, Overflow, Kodierung, Komplement, BCD, Floating_Point |
| **PowerShell** | Cmdlets, Loops, Functions, ErrorHandling, Modules, Registry, WMI, Remoting, JSON, Pipeline |
