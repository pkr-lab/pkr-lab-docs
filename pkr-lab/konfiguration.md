# Konfiguration

Die README nutzt Shields.io-Abzeichen. Angepasst werden die Abzeichen direkt in der `README.md`:

| Abzeichen | Quelle |
|---|---|
| GitHub, Followers | `img.shields.io/badge/GitHub-pkr--lab` und `img.shields.io/github/followers/pkr-lab` |
| Achievements | statische Abzeichen, von Hand gepflegt |

Das Layout (zentrierter Block mit HTML-`div`) steht ebenfalls in der README.
